# 감사 결함 수정과 릴리스 완료 기준

사용자가 2026-09-12 감사에서 제시한 F01–F24 전체 수정을 승인했다. 현재 작업 브랜치의 기존 Frame 전환과 UniFFI 변경을 보존하면서, 데이터 격리·종료·최적화 경로·개발 도구·검증의 결함을 수정한다.

- F01/F06/F10/F11/F24: React 캐시는 엔진 범위로 격리하고 유한 수명과 정리 API를 제공한다. Set/바이너리 입력을 구분하고 이전 엔진·명령·구독의 결과를 새 범위에 전달하지 않는다. 실제 React 렌더링으로 검증한다.
- F02/F07/F08/F09: bootstrap 등록의 소유권을 추적한다. 종료된 초기화 결과는 설치하지 않고 자원을 한 번 닫는다. 종료 후 반환된 엔진과 전역 엔진 호출은 거부한다. 재생성 및 reload 경합에서도 다른 등록을 손상시키지 않는다.
- F03/F04/F12/F23: raw 호출에도 State를 주입하고 중첩 호출은 상태를 격리한다. Frame 응답 한도는 헤더를 포함해 direct와 fallback에 동일하게 적용한다. 바이너리 채널 수를 진단에 포함한다.
- F05: Tauri JS 채널은 호출 WebView에 귀속한다. 다른 WebView는 수신·종료할 수 없고 소유 WebView 종료 시 정리한다.
- F13/F14: 개발 감시는 설정 변경 및 새 하위 디렉터리를 반영하고 OS 감시 오류에서 복구하거나 명확히 실패한다.
- F15/F16: UniFFI 라이브러리 경로는 Cargo 산출물을 기준으로 한다. 빈 임시 경로에 실제 바인딩을 생성하고 비교·교체한다.
- F17/F18/F19/F20/F21/F22: API 선언·subpath·Rust 공개 타입을 검사하고 세 퍼징 타깃의 corpus를 연결한다. 프로세스 검사는 지원 런타임에서 실행한다. frozen 설치와 문서 버전·릴리스 계획을 일치시킨다.
- F24: hot-core의 안전을 위한 라이브러리 보관은 유지하고 누적 로드 및 재시작 필요성을 관측할 수 있게 한다.

완료는 회귀 테스트, 전체 로컬 검사, 소비자 패키지 검증, 변경된 동일 커밋의 CI 근거를 구분해 기록한다. 실제 기기 실행이나 장시간 퍼징을 수행하지 않았다면 통과로 기록하지 않는다. 기존 사용자 iOS 생성물은 변경하거나 커밋하지 않는다. 이미 발행된 0.9.0을 덮어쓰지 않는다. 사용자에게 열린 0.9.0 작업의 정확한 대상을 확인하며, 불명확한 발행·병합은 독립적인 수정 작업을 막지 않는다.
