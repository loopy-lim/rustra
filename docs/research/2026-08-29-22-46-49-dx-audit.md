# 리서치: DX 관점에서 불완전하거나 추가해야 할 항목 감사

**날짜**: 2026-08-29 22:46:49 +0900

## 연구 질문

DX(개발자 경험) 측면에서 불완전하거나 추가해야 할 것들을 확인한다. 5개 영역(CLI 표면, 문서 정확도, TS 패키지 표면, Rust 저작면, 백로그/이력)을 병렬 조사.

## 요약

- **developer-hurdle-reduction 계획(2026-08-29)으로 doctor/codegen/dev/drift 게이트는 착지**했으나, CLI 인체공학(--help 부재, init 덮어쓰기, config 오타 silent ignore)과 문서 정확도(컴파일 불가 예제, 폐기된 시그니처)에 HIGH 결함이 남아 있다.
- **가장 즉각적인 실행 항목은 버전 스큐**: testing/devtools/react 0.4.1이 `@rustra/types ^0.5.0`에 의존하는데 대기 중 changeset이 patch라 해소되지 않음.
- **가장 큰 사용자 가치 갭은 이벤트 표면**: Node/Bun subscribeEvent ❌, Tauri 채널 ❌, 타입 안전 이벤트 코드젠 ❌.
- TS 런타임은 디버깅 지원이 약함(RUSTRA_DEBUG 전무, 원본 에러 cause 소실, 응답 셰이프 무검증).
- Rust 저작면은 매크로 진단 품질이 양호하나, fn doc comment가 TS JSDoc으로 전달되지 않는 **죽은 코드**(`__RUstra_doc_`)와 코드젠 unknown 폴백 무경고가 HIGH.
- 과거 후속 목록(invoke_typed2, caller-buffer, UTF-8 3벌 등)은 코드 재검증 결과 대부분 소진 완료 — 진짜 미해결 축은 5개로 수렴.

### 5. 백로그/이력 재검증

**진짜 미해결 축 (코드 재검증 완료)**
1. **버전 스큐 0.4.1↔0.5.0** — testing/devtools/react 0.4.1이 `@rustra/types ^0.5.0` 의존. 대기 중 changeset `.changeset/quiet-bridges-check.md:2-7`이 전부 **patch**라 0.4.2에 그쳐 해소 못 함. **가장 즉각적·저위험 고임금.**
2. **Node/Bun 이벤트 표면** — `docs/compatibility-matrix.md:15-16`: Node/Bun subscribeEvent ❌(node는 drainEvents 폴링만, node/src/index.ts:424), Tauri 채널 ❌, 타입 안전 이벤트 코드젠 미착수. **가장 큰 사용자 가치 갭.**
3. **배치 항목별 취소 네이티브** — `packages/types/src/rkyv-engine.ts:670-672`에 "명시적 미지원 계약"으로 고정. 취소 필요 시 배치 고속 경로 포기 + 항목별 N회 횡단.
4. **async 실행기 주입 훅** — `crates/rustra/src/executor.rs:20-33`: 현재 스레드 park 방식이라 tokio 워커 굶김 위험 + `State<T>` thread_local 제약. Tauri(tokio) 호스트가 직접 관리해야 함.
5. **의도적 별트랙** — 프리빌트 바이너리 전략, WASM/Electron 패키지, 무중단 주입(release frozen registry), Windows 검증, 영어 문서(README 3줄 요약만 존재).

**기타**: JSI caller-buffer 실기기 측정 부재(영수증 3건 모두 호스트 측정 — docs/benchmarks.md:30-32), RN podspec/gradle 상대 경로가 모듈 깊이 하드코딩(examples/react-native-bare-calculator/modules/rustra-bridge/RustraBridge.podspec:12 — CLI 템플릿은 react-native.ts:26,322에서 relative() 계산 시작), 루트 `doctor.config.json` 이름 충돌(rustra doctor와 무관한 react-doctor 설정).

**해소 확인 (더 이상 열려있지 않음)**: invoke_typed2(→invokeTypedRaw/Buffer/Pos/ById로 대체), caller-buffer 트랙 C 3종, positional facade, 배치 byId, RendererHost 고아(doc(hidden)+deprecated), UTF-8/abort-race/JSON 엔진 3벌 복제, 갓모듈 분해(lib.rs 280줄, types facade 20줄 + 11모듈), Node stdio contract-hash, int64 bigint 복원, crates.io 메타/이슈 템플릿/SECURITY.md, packed RN consumer CI.
