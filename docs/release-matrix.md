# Release registry matrix

This matrix is generated by the read-only registry audit. It records each workspace version independently; packages are not required to share a version.

```bash
fnm exec --using=22 node scripts/audit-release-registry.mjs \
  --output /tmp/rustra-m0/registry-audit.json \
  --artifact packages/react-native/native/cpp/RustraJSIBridge.cpp \
  --artifact packages/react-native/native/android/rustra-jsi-jni.cpp \
  --artifact packages/react-native/native/ios/RustraJSIModule.mm \
  --artifact examples/react-native-bare-calculator/generated/.rustra-generated.json
```

`--output receipt.json` writes the complete JSON receipt and a sibling `receipt.md`. `--artifact PATH` is repeatable. The command never publishes, installs, or extracts an archive to disk.

## Evidence contract

For npm, the audit reads the package document and records the exact workspace version, the `latest` dist-tag, `gitHead`, and the complete `dist` object. It validates the document shape, distinguishes an absent exact-version key from a present invalid value, checks the exact entry's package name and version, and requires an HTTPS tarball plus a valid SHA-1 `shasum` or SRI `integrity`. A package-level 404 or a well-formed document with a missing exact version is `unpublished`; a timeout, network failure, or malformed registry response is `query-error` and makes the command exit nonzero.

For crates.io, the audit validates each sparse-index entry with complete SemVer syntax, finds the exact workspace version and newest non-yanked version, and records whether the exact version is yanked. “Newest” includes a valid prerelease when SemVer precedence places it above all other non-yanked entries; it does not invent a stable-only policy distinct from the index. The audit downloads the exact `.crate` and verifies its SHA-256 against the index checksum. Only after checksum verification does it read the exact `<crate>-<version>/.cargo_vcs_info.json` path directly from the bounded in-memory tar archive. A timeout, query, malformed or truncated archive, missing VCS file, parse, or checksum failure makes the command exit nonzero.

Source relation is deliberately narrow:

| Relation    | Meaning                                                                                                     |
| ----------- | ----------------------------------------------------------------------------------------------------------- |
| `exact`     | A full 40-hex registry revision equals the candidate `HEAD`, and crate VCS metadata is clean.               |
| `different` | Registry revision is present and differs from the candidate. This is a valid mixed or older release result. |
| `unknown`   | The registry lacks a full 40-hex revision, or crate VCS metadata is dirty. It is never treated as a match.  |

The candidate receipt includes `HEAD`, worktree dirty state, and UTC fetch time. Local artifact hashes identify only the named generated/native bytes. They do not prove registry contents, package installation, host integration, physical-device execution, or long-duration behavior.
