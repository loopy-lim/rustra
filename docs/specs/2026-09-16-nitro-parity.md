# Nitro 동급 이상 성능 개선

## 목표와 기준판

발행된 Rustra 0.10.2 (`8db7279cd30cf50ab1ba625f325a11a832697891`)에서 출발한다. 사용자 요청은 작은 호출, 복합 데이터/트리, 반복 탐색을 모두 개선하고 Nitro와 다시 비교하는 것이다. Nitro Modules와 nitrogen은 공식 최신 안정판 0.37.1로 고정한다. 과거 0.35.10 결과와 새 결과를 합치지 않는다.

## 비교 계약

- 같은 Release 앱, Hermes, 동일 입력/출력 값과 소유권, 동일 알고리즘을 사용한다.
- 동기 호출에는 Promise/await를 삽입하지 않는다. 공개 비동기 API 비교는 별도 표다. 내부 native 호출은 진단이며 공개 API 성과로 세지 않는다.
- 숫자 add, 문자열, pair, 64B/64KiB/정확한 기본 wire 한도 내 byte buffer를 포함한다.
- 복합 트리는 ID, 문자열, enum 또는 동등한 태그, optional, metadata, 자식 관계를 포함한다. 동일한 표현으로 양쪽에 전달한다. Nitro가 재귀 DTO 생성을 지원하지 않으면 동일한 flat arena tree를 별도 명시하여 양쪽에 사용한다. Rust에만 유리한 표현 변환을 제외하지 않는다.
- 균형 255/1023/8191노드와 넓은 1025노드를 기본 대상으로 한다. 전체 왕복, 전체 입력+마지막 노드 DFS, 양쪽 모두 native에 보관한 DFS, 양쪽 모두 동일한 인덱스로 조회하는 경로를 구분한다. 보관/인덱스 구축과 갱신은 조회와 별도 계측한다.
- 정답, 방문 수, 누락 ID, fresh-output 소유권을 timing 전에 검증한다. 왕복은 전체 값이 동일해야 한다.
- 호출 순서를 교차하고 독립 프로세스 5회 이상 실행한다. 짧은 동기 연산은 batch timing으로 타이머 비용을 상각하고 결과 checksum을 소비한다. p50/p95, 반복 분포, paired ratio와 95% CI, 실제 바이트/노드 수, 버전, 소스/생성물/바이너리 hash를 기록한다.
- 동급: 사전 고정한 ±5% 등가 구간 안에 95% CI 전체가 들어온다. 우위: ratio CI 상한 < 1.0. CI 상한 <= 1.05지만 하한 < 0.95이면 최소 동급 이상으로 분류한다. 불확실하거나 느린 case를 감추지 않는다.
- iOS Simulator는 일차 진단 환경이다. 물리 Android 결과는 별도 표로 기록하며 기기 간 수치를 섞지 않는다. 설치 전 기존 벤치 앱/사용자 데이터를 보존하고 전용 앱 ID를 사용한다.

## 구현 방향

먼저 공정한 비교에서 느린 경로를 재현한다. 기존 Promise API의 동작은 유지하면서 동기 transport를 위한 명시적 typed synchronous binding을 추가할 수 있다. 지원하지 않는 transport/비동기 명령을 동기로 우회하지 않는다. 계약 검증, 엔진 세대 변경, 오류/재진입, payload 한도는 유지한다.

동기 실행 가능 여부는 Rust 명령 생산자가 선언하고 생성된 계약과 현재 native 정보로 확인한다. 현재 매크로의 async wrapper는 일반 함수와 구분되지 않으므로 원래 실행 종류를 별도 메타데이터로 보존해야 한다. 정보가 없거나 검증에 실패한 명령은 새 동기 binding을 거부한다. 기존 Promise API의 허용 범위는 바꾸지 않는다. 이 메타데이터 추가로 계약 hash는 바뀔 수 있지만 요청/응답 wire와 FFI 함수 형식은 유지한다.

정적 복합 코덱의 반복 분기, 임시 객체, 메모리 할당을 프로파일링한다. 효과가 반복 측정으로 입증된 변경만 채택한다. 트리 보관/인덱스 예제는 양쪽에 동일한 알고리즘과 갱신 정책을 사용하며, 데이터 구조 개선을 Rustra bridge 자체의 우위로 포장하지 않는다.

## 안전성과 완료

API/wire/FFI 호환성, handler 단일 실행, 입력 제한, 누수 방지를 보존한다. 생성 파일은 생성기를 통해 갱신한다. 관련 TS/Rust/C++ 테스트와 native Release 실행을 검증한다. 최종 결과가 목표를 충족하지 않으면 차이와 남은 원인을 명시한다. 현재 요청은 구현·재측정이며 새 버전 발행 완료로 간주하지 않는다.

## 2026-09-16 구현과 측정 상태

공개 동기 binding, 생성 JSI 코덱·Rust complex 코덱 및 숫자 raw 호출의 일반적인 비용을 줄이고, 동일 후보를 iOS Simulator와 물리 Android에서 각각 5회×90항목 검증했다. 공개 동기에서 동급 이상은 iOS18/30, Android19/30이며 **전 항목 Nitro 동급 이상 목표는 미달**이다. 문자열·pair·indexed와 일부 resident/버퍼 결과의 차이를 남긴다. [전체 결과와 근거](../research/2026-09-16-nitro-parity-candidate.md)는 모든180항목과 실패한 중간 실행을 포함한다.

구현·독립 검토·일반 회귀 테스트·반복 native 측정은 수행했다. 추가 무작위 스트레스 검사는 사용자 요청으로 중단했다. 현재 소스의 전체 플랫폼 인증 또는 새 버전 발행은 완료로 표시하지 않는다. 사용자 승인으로 로컬 커밋을 완료했다. PR/발행은 후속 단계다.

### 2026-09-16 잔여 차이 후속 검증

[후속 PLAN](../plans/2026-09-16-nitro-parity-followup.md)에 따라 Android 버퍼의 순서 의존성, 실제 DFS의 보관 용량·스택 성장, 작은 호출 후보 및 큰 객체 직렬화를 조사했다. 작은 맵 인코더를 개선했고 악화된 postcard 후보는 폐기했다. 새 iOS/Android Release의 각 5회×90항목에서 공개 동기는 양쪽 20/30, Promise API는 iOS19/30·Android20/30이 동급 이상이다. 전 항목 목표는 미달이며 모든 판정·진단 한계는 [후속 결과](../research/2026-09-16-nitro-parity-followup.md)에 남겼다. 새 발행이나 플랫폼 인증 완료로 처리하지 않는다.
