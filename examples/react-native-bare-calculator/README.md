# Bare React Native zero-config fixture

A fixture that verifies TypeScript interpretation of the Rustra generated package and
iOS/Android autolinking on React Native 0.81 without an Expo dependency.

```bash
bun install
bun run codegen
bun run typecheck
bun run test:autolink
```

`rustra.json` only specifies the location of the app crate in the monorepo. The Cargo
package/library, Podspec, Gradle, CMake, and JavaScript bootstrap are inferred or
generated by the generator.

```ts
import { addNumbers } from './generated/react-native';

const result = await addNumbers({ a: 20, b: 22 });
```

[`App.tsx`](App.tsx) is a complete screen example that goes from Button → generated command
→ React state update without Expo imports or manual native installation. Real apps use
the same `@rustra/generated-react-native` autolink package.

This fixture verifies the autolinking contract and does not substitute for simulator/device
runtime evidence. Real native build/link is covered by the iOS/Android CI of the Expo
comparison app and local native build gates.
